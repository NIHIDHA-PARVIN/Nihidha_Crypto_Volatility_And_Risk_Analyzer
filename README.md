# Crypto Volatility and Risk Analyzer

This project analyzes live cryptocurrency market data, evaluates short-term price movements, and compares market volume trends using Python.

## Features
- Fetches live market data for multiple cryptocurrencies using CoinGecko API
- Generates a formatted table showing:
  - Price (USD)
  - 24-hour percentage change
  - 24-hour trading volume
- Displays directional indicator for price change (positive/negative)
- Plots 7-day historical trend chart for Solana (SOL)
- Shows "Last Updated" timestamp on visualization
- Generates bar chart comparing 24h trading volume across cryptocurrencies

## Technologies and Libraries Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- CoinGecko REST API

## Files in This Repository
- `crypto_module1.ipynb` — Main notebook containing all code, outputs, and charts
- `task1.ipynb` — Initial exploratory notebook (reference)

## Output Visualizations (Inside Notebook)
- 7-day Solana price chart
- Live market comparison table
- Bar graph for trading volume
- Timestamp on trend chart
